# ntp-time

Небольшая утилита на Go для получения точного текущего времени через NTP (Network Time Protocol).

## Что делает

Программа запрашивает текущее время у NTP-сервера и выводит его в консоль. В случае ошибки текст ошибки выводится в STDERR, а программа завершается с ненулевым кодом выхода.

## Запуск


```bash
go run .
```
