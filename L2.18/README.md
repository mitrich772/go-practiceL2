# Календарь событий (HTTP-сервер)

Простой HTTP-сервер для управления календарем событий с поддержкой CRUD-операций и фильтрации по дням, неделям и месяцам.

## Основные возможности

* `POST /create_event` — создать новое событие
* `POST /update_event` — обновить существующее событие
* `POST /delete_event` — удалить событие
* `GET /events_for_day` — получить события за день
* `GET /events_for_week` — получить события за неделю
* `GET /events_for_month` — получить события за месяц

События хранятся в памяти в map.

## Формат запросов

* POST: `application/json`
* GET: параметры через query string (`?user_id=1&date=2023-12-31`)

## Формат ответов

Успех:

```json
{"result": ...}
```

Ошибка:

```json
{"error": "описание ошибки"}
```

## Коды статуса

| Код | Значение                    |
| --- | --------------------------- |
| 200 | OK                          |
| 400 | Некорректные входные данные |
| 503 | Ошибка бизнес-логики        |

## Логирование

Все запросы логируются: метод, URL и время выполнения.

## Конфигурация

Порт запуска сервера задаётся через флаг:

```
-p 1235
```

## Архитектура

* Бизнес-логика вынесена в отдельный пакет `service/`
* HTTP-слой только вызывает методы сервиса
* Unit-тесты покрывают основные функции бизнес-логики
