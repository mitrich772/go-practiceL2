# Утилита grep

Небольшая утилита на Go — фильтрация текстового потока (аналог команды `grep`).

## Что делает

Читает входной поток (файл или STDIN) и выводит строки, соответствующие заданному шаблону. Поддерживает регулярные выражения и фиксированные строки, контекст вывода и ряд флагов для управления поведением.

## Запуск

```bash
# Поиск в файле, вывести совпадающие строки с номерами:
go run . -n "pattern" filename.txt
```
