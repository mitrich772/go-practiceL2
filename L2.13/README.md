# Утилита cut

Небольшая утилита на Go — аналог команды `cut` для разбора строк по разделителю и вывода указанных полей.

## Что делает

Считывает строки из файла (или STDIN, если имя файла не указанo) и выводит выбранные поля каждой строки, разделённые заданным разделителем.

## Запуск


```bash
# вывести поля 1 и 3..5, разделитель - запятая:
go run . -f 1,3-5 -d "," input.txt
```
