# Утилита telnet (примитивный telnet-клиент)

Простая консольная утилита на Go для установления TCP-соединения с сервером и интерактивного обмена данными, аналогично базовому `telnet`.

## Что делает
Программа устанавливает TCP-соединение с указанным хостом и портом.  
Все данные, вводимые пользователем в STDIN, отправляются на сервер, а все данные, полученные от сервера, выводятся в STDOUT.

Работа ввода и вывода выполняется параллельно в отдельных горутинах.

## Запуск

```bash
go run . -h example.com -p 23
