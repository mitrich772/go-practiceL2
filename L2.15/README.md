# Minishell: взаимодействие с ОС

Небольшой простой shell на Go для взаимодействия с операционной системой.

## Что делает

Интерпретатор командной строки, поддерживающий встроенные команды (cd, pwd, echo, kill, ps), запуск внешних программ через exec, а также пайплайны (`|`) для передачи вывода одной команды на ввод другой.

## Запуск

Для запуска проекта достаточно выполнить:

```bash
go run .
```

Или запустить скрипт:

```bash
go run . script.sh
```
