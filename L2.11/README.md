# L2.11 — Поиск анаграмм в словаре

Небольшая функция на Go для поиска множеств анаграмм в заданном словаре слов.

## Что делает

На вход подаётся срез строк (русские слова в Unicode). Функция находит множества анаграмм, возвращая `map`, где ключ — первое встретившееся слово множества, а значение — отсортированный по возрастанию срез всех слов множества. Слова без анаграмм в выход не попадают. Все слова приводятся к нижнему регистру.

## Запуск

Пример запуска небольшого демонстрационного `main`:

```bash
go run .
```
