# Утилита wget (упрощённая)

Консольная утилита на Go для загрузки веб-страниц и вложенных ресурсов с возможностью рекурсивного обхода ссылок, аналогично `wget -m`.

## Что делает
Программа принимает URL и глубину рекурсии, скачивает HTML-страницы, а также все связанные ресурсы (CSS, JS, изображения и т.д.) и страницы по ссылкам в пределах одного домена.  
В результате формируется локальный каталог с копией сайта, доступной для офлайн-просмотра.

## Запуск

```bash
go run . -u https://example.com -n 2 -o ./res
```
