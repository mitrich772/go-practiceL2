# Утилита sort

Небольшая утилита на Go — упрощённый аналог UNIX‑команды `sort` для сортировки строк.

## Что делает

Читает строки из файла или STDIN и выводит их в отсортированном виде. Поддерживает набор флагов (см. ТЗ).

## Запуск

Для мини‑проекта достаточно выполнить:

```bash
# сортировать по 2-му столбцу (разделитель — табуляция):
go run . -k 2 input.txt

# числовая сортировка в обратном порядке + только уникальные строки:
go run . -nr -u input.txt

# сортировать по названию месяца и игнорировать trailing blanks:
go run . -M -b input.txt

# записать результат в файл (result_<имя_файла>):
go run . -f input.txt
```
