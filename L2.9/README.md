# Распаковка строки

Небольшая утилита/функция на Go для примитивной распаковки строк с повторяющимися символами.

## Что делает

Функция распаковывает строки вида `a4bc2d5e` в `aaaabccddddde`, поддерживает экранирование через `\` и обрабатывает ошибочные входные данные.

## Запуск


```bash
go run .
```

Или собрать бинарник:

```bash
go build -o unpack .
./unpack
```
