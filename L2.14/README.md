# L2.14 — Функция or (объединение done-каналов)

Небольшая утилита/функция на Go, объединяющая несколько каналов сигнала завершения в один.

## Что делает

Функция `or` принимает один или более каналов `<-chan interface{}` и возвращает канал того же типа, который закрывается сразу после закрытия любого из переданных каналов.

## Запуск

Для запуска примера в корне проекта достаточно:

```bash
go run .
```
